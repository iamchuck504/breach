# Backup de modelos procedurales

Copia previa al reemplazo visual bulky-chibi v2, creada el 2026-08-18.

- `rig.js`: rig, cinco variantes y modelos de SMG/escopeta.
- `drops.js`: integración de las armas procedurales como drops.
- `shot-charsel.png`: selector con las cinco variantes anteriores.
- `pose-*.png`: referencias visuales de idle, aim, cover y roadie.

Para restaurar el modelo anterior, copiar `rig.js` de esta carpeta sobre
`src/player/rig.js` y volver a compilar el proyecto.
